# Mini-HDFS Frontend (Next.js + shadcn/ui)

A modern React frontend for uploading files to Mini-HDFS.

## Setup

1. **Install dependencies:**
```bash
cd client/frontend
npm install
```

2. **Run the development server:**
```bash
npm run dev
```

The frontend will run on `http://localhost:3000` and proxy API requests to `http://localhost:8000`.

## Features

- 🎨 Beautiful UI with shadcn/ui components
- 📤 Drag and drop file upload
- 📊 Real-time upload progress
- ✅ Success/error feedback
- 📱 Fully responsive design

## Tech Stack

- **Next.js 14** - React framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **shadcn/ui** - UI components
- **Lucide Icons** - Icon library

## Note

Make sure your backend is running on port 8000 before using the frontend.
